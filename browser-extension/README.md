# Tempo Stats — Browser Extension

Browser extension for tracking music playback on supported web audio players (YouTube Music, Spotify Web, SoundCloud, Apple Music) and syncing scrobbles to Tempo for Android over Wi-Fi.

## Features

- **Position-based tracking**: Uses HTML `<audio>` and `<video>` timestamp data (`currentTime`) to measure duration.
- **Playback events**: Detects pause, seek, replay, and track completion.
- **Known Artist whitelist**: Enables tracking on ambiguous domains when the channel or artist matches your saved list.
- **YouTube opt-in**: Allows tracking specific YouTube channels by name.
- **Offline queueing**: Saves plays in IndexedDB when disconnected and syncs upon reconnection.
- **Local network discovery**: Connects to the Android app via local IP on Wi-Fi or mobile hotspot.
- **HMAC-SHA256 authentication**: Signs payload requests with a shared token generated by the phone app.
- **Popup UI**: Dark theme interface showing current playback state, pending sync queue, and session statistics.

## Installation

### From Source

1. **Build the extension**:
   ```bash
   cd browser-extension
   npm install
   npm run build
   ```

2. **Load in Chromium browsers (Chrome, Edge, Brave)**:
   - Open `chrome://extensions/`.
   - Enable **Developer mode** using the toggle.
   - Select **Load unpacked**.
   - Choose the `browser-extension/dist` directory.

3. **Pair with Tempo Android app**:
   - Open the Tempo Stats popup.
   - Select the **Pairing** tab.
   - Enter your phone's local IP address, port (`8765`), and token.
   - Click **Connect**.

### Development Watch Mode

```bash
npm run watch
```

## Architecture

```
Content Script (per tab)     →  Background Service Worker  →  Phone (Wi-Fi)
Reads MediaSession + DOM         PlaybackTracker state         POST /api/plays
every 2 seconds                  machine                       HMAC-SHA256 signed
                                 ↓
                                 IndexedDB (queue)
```

### Key Modules

| Path | Description |
|---|---|
| `src/content/media-probe.ts` | Reads DOM element properties and MediaSession state. |
| `src/background/tracker.ts` | Core state machine for position tracking. |
| `src/background/site-detect.ts` | Domain matching and channel whitelist check. |
| `src/background/normalize.ts` | Title and artist text cleanup. |
| `src/background/sync.ts` | Local network HTTP client and HMAC signing engine. |
| `src/background/storage.ts` | Wrapper for `chrome.storage.local` and IndexedDB. |
| `src/background/service-worker.ts` | Extension lifecycle and event routing. |
| `src/popup/` | Extension popup user interface. |

## Technical Differences from Desktop App

| Capability | Desktop Application | Browser Extension |
|---|---|---|
| **Position tracking** | OS media session events | Direct `<audio>.currentTime` readings |
| **Site identification** | Window title parsing | Direct `tab.url` matching |
| **Mute detection** | System audio volume APIs | Direct `<audio>.muted` state |
| **Process overhead** | Inter-process polling | Browser-native event listeners |

## Protocol Specifications

The extension uses Tempo's standard HTTP sync protocol:
- Endpoint: `POST /api/plays`
- Header: `X-Tempo-Signature` containing the HMAC-SHA256 digest calculated using the authorization token.
